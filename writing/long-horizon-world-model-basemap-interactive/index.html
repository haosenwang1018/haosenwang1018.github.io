统一框架：一条会崩的执行回路

把「长程」想成一个机器人要完成一个很长的任务:看见现在 → 记住过去 → 预测未来 → 验证「是不是真发生了」 → 规划下一步 → 动手 → 被评测。这条回路的每一环都会崩,每种崩法就是一个研究方向;下面的论文,基本都在修其中某一环。

感知→ 记忆 · 持久性→ 预测 · 漂移 / 序列形态→ 验证 · 事件→ 规划 · 闭环 / 信任时域→ 行动 · 时间抽象→ 评测 · 什么才是对的指标
