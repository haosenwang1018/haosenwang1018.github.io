PRISM-WM: A World Model Should Not Average Contact Away

June 2026

PRISM-WM pushes the question down to the transition function repeatedly called by the planner: this interface has to represent hybrid dynamics, not average contact, sliding, and landing into one smooth curve.

TD-MPC made the world model a much more concrete control interface.

The model does not need to reconstruct the whole world. It needs to provide useful futures before the agent acts: the current observation is encoded into a latent state, the planner tests candidate action sequences in that latent space, and reward/value models score the imagined trajectories.

The pressure falls on the prediction interface that the planner calls repeatedly.

transition function

\[ \hat z_{t+1}=d_\theta(z_t,a_t) \]

This function answers a simple question: if the model is currently at latent state zₜ and tries action aₜ, what should the next latent state be?

A rollout is not one prediction. Starting from the current zₜ, the planner evaluates candidate action sequences by calling the dynamics model again and again.

latent rollout

\[ \begin{aligned} (z_t,a_t) &\xrightarrow{d_\theta} \hat z_{t+1} \\ (\hat z_{t+1},a_{t+1}) &\xrightarrow{d_\theta} \hat z_{t+2} \\ (\hat z_{t+2},a_{t+2}) &\xrightarrow{d_\theta} \hat z_{t+3} \\ &\cdots \end{aligned} \]

Each candidate trajectory is scored by the reward model and the terminal value. The planner picks the best trajectory, executes only the first action, and replans at the next step.

The question lands here: if dθ smooths over the physical regime switches that matter for control, what exactly is the planner trusting when it rolls out futures?

Contact Is Not A Smooth Curve

Robotic locomotion, jumping, obstacle avoidance, and manipulation are not governed by one smooth function.

A foot before ground contact follows one kind of dynamics. The same foot after impact follows another. An object before grasping is one state; after grasping, contact forces, friction, and constraints change the system. The paper calls these systems hybrid systems: continuous motion interrupted by discrete regime switches.

Terminology

Here, regime means a local dynamics mode. A foot in the air, a foot in ground contact, and a grasped object follow different local rules; a regime switch is the transition between those modes.

The TD-MPC / TD-MPC2-style latent world models compared by PRISM-WM often use one monolithic MLP for the transition.

monolithic transition baseline

\[ (z_t,a_t)\rightarrow \mathrm{MLP}\rightarrow \hat z_{t+1} \]

monolithic MLP

Monolithic means a single unified network: all states and actions are handled by the same MLP. MLP means multilayer perceptron, the standard fully connected neural network. Here it refers to the monolithic TD-MPC2 / MLP baseline in the PRISM-WM paper, not to a separate paper named "standard latent world model."

A useful first approximation: an MLP maps one fixed-length vector to another. Here, it maps (zₜ, aₜ) to the next latent state. LLMs also use MLPs: a Transformer block usually contains attention plus an MLP / FFN.

In principle, this MLP can approximate a complex function. In practice, it can learn an averaged version of several incompatible regimes. Stance and flight, sticking and sliding, support force and friction residual can all get mixed into one continuous map. The error may look tolerable for one-step prediction. For planning, it compounds: every extra imagined step asks the planner to trust the same smoothed dynamics again.

stance The support phase. A foot is in contact with the ground and carries load.
flight The airborne phase. A foot has left the ground and receives no support force.
sticking A contact state with little or no relative sliding, close to static friction.
sliding A contact state where the contact point moves along the surface, entering kinetic friction.
support force The reaction force from the ground on the foot or body. It determines whether the robot can stand, jump, land, or recover balance.
friction residual The remaining change that friction or sliding has to explain after the main motion has been modeled; in PRISM-WM, it corresponds to friction-related components in latent residual dynamics.

What TD-MPC Keeps, And What PRISM-WM Changes

That is PRISM-WM's entry point. TD-MPC already solves the first compression problem: do not reconstruct every observation detail; learn a task-oriented latent state useful for control. PRISM-WM asks the second question: if the dθ repeatedly called by the planner is still one monolithic continuous function, will it average away the boundaries of hybrid dynamics?

At this point, the TD-MPC / PRISM-WM boundary needs to be made explicit. In TD-MPC, the model is TOLD: Task-Oriented Latent Dynamics. It contains at least these interfaces.

Interface Role
zₜ = hθ(oₜ) Encode the current observation into a task-oriented latent state.
ẑₜ₊₁ = dθ(zₜ, aₜ) Predict the next latent state from the current latent state and action.
r̂ₜ = Rθ(zₜ, aₜ) Predict the immediate reward.
terminal value Vθ Estimate remaining return from the predicted terminal latent state after an H-step rollout.

Here θ is the usual notation for learnable neural-network parameters. hθ is the encoder / representation network; zₜ is the latent state at time t; aₜ is the action at time t. The planner is not the world model itself. It is the algorithm that uses the world model to search over action sequences. Strictly, the world model is also not identical to the transition function; the transition function is the part that most directly predicts the future.

PRISM-WM therefore does not reject TD-MPC. It keeps the encoder that produces zₜ, the planner that rolls out in latent space, and the reward/value models that score trajectories. It changes the parameterization of dθ, replacing a single monolithic MLP with gated, orthogonalized expert residual dynamics.

The Interface PRISM-WM Changes

PRISM-WM's core equation is short.

gated residual update

\[ \hat z_{t+1}=z_t+\sum_{k=1}^{K}w_{t,k}v_k(x_t) \]

Read it piece by piece:

  • zₜThe current latent state.
  • aₜThe candidate action.
  • xₜUsually the concatenation of zₜ and aₜ.
  • wₜ,ₖHow much the kth expert is used at this step.
  • vₖ(xₜ)The residual direction proposed by the kth expert under the current context.

Routing weights

The gating network can be read as a small routing network. It looks at the current context, usually the latent state and action, and gives each expert a raw score sₜ,ₖ.

\[ w_{t,k}=\frac{\exp(s_{t,k})}{\sum_{j=1}^{K}\exp(s_{t,j})}, \qquad \sum_{k=1}^{K}w_{t,k}=1 \]

Softmax turns those raw scores into non-negative weights that sum to 1. So wₜ,ₖ has a direct meaning: how much the model should trust the kth expert for this step. The weight is not the prediction itself; the actual change direction is vₖ(xₜ).

PRISM-WM changes the dynamics function from one MLP into a composition of local dynamics primitives.

gate + experts

\[ \begin{aligned} (z_t,a_t)&\xrightarrow{\mathrm{gate}}\{w_{t,k}\}_{k=1}^{K} \\ &\xrightarrow{\mathrm{experts}}\sum_{k=1}^{K}w_{t,k}v_k(x_t)\rightarrow \hat z_{t+1} \end{aligned} \]

The gate is not meant to explicitly name "left foot support" or "right foot in flight." The paper is careful about this: after Gram-Schmidt orthogonalization, an expert should not be forced into a one-to-one interpretation as a physical event. A better reading is that the experts provide non-redundant directions in latent residual space. Physical modes are represented by how the gate combines these directions.

PRISM-WM does not hand-write one expert per contact state. It learns a composable residual basis and lets the current (zₜ, aₜ) decide how to mix it.

Why MoE Alone Is Not Enough

Replacing one MLP with multiple experts does not automatically solve the problem.

If all experts learn the same function, the MoE is only a larger MLP. It has more parameters, while the regimes remain entangled. PRISM-WM adds latent orthogonalization as the key structural bias.

In the paper, each expert first outputs a vector uₖ. A stable Gram-Schmidt step turns it into vₖ.

orthogonalized residual basis

\[ \begin{aligned} \tilde v_k &= u_k - \sum_{i=1}^{k-1}\langle v_i,u_k\rangle v_i \\ v_k &= \frac{\tilde v_k}{\lVert \tilde v_k\rVert_2+\epsilon} \end{aligned} \]

The operation is concrete: later experts subtract the part already explained by earlier basis directions. The resulting vₖ vectors are less likely to collapse into the same direction.

This is the taste of the design. The model does not freeze "physical mode" into a label. It gives the dynamics residual a structural preference: explain the future using directions that are not redundant. Contact, sliding, landing, and balance recovery can then appear as changes in gate weights over those basis directions.

This distinction explains why the paper emphasizes orthogonalized MoE rather than vanilla MoE. Vanilla MoE increases capacity. Orthogonalization tries to reduce expert redundancy. The former makes the model larger; the latter makes the model more like a decomposition of the dynamics problem.

Evidence: Does It Reduce Rollout Drift?

The most important metric in this paper is long-horizon fidelity. A single reward number only describes control performance at one training point. Horizon-dependent fidelity directly tests the paper's world-model claim.

If the story is correct, PRISM-WM does not need to look spectacular at very short horizons. As the rollout horizon grows, the monolithic MLP should drift faster, while the orthogonalized MoE should keep the latent trajectory aligned for longer.

In Fig. 8, the monolithic MLP loses latent cosine similarity more quickly as the horizon increases. MoE and orthogonalized MoE stay more stable. The reward-fidelity plot on the right adds an important nuance: a larger vanilla MoE is not always better, because over-parameterized experts can still learn redundant representations.

What The Paper Changes

PRISM-WM concentrates the architectural change on the transition function inside TD-MPC.

The planner calls this function repeatedly during rollout. If the function averages away contact modes, reward prediction, value estimation, and action selection all move through the wrong future.

The paper therefore gives a concrete standard: if a world model serves a planner, its transition function has to handle contact, sliding, landing, and other dynamics switches. Preserving task-relevant information is not enough; the dynamics structure also has to be right.

TD-MPC's pressure was: do not spend capacity reconstructing irrelevant details. PRISM-WM asks the next question: if the model already learns only latent dynamics, can that latent dynamics still average away the physical regimes that planning depends on?

  • Repeatedly called objectThe planner relies on dθ at every rollout step.
  • Core failure modedθ smooths over contact boundaries.
  • Evidence to inspectLong-horizon latent fidelity; one-step reward is not enough.

What Remains Unresolved

Can the number of regimes be discovered automatically?

The main experiments use K=4, and Fig. 10 shows that different expert counts behave differently. The paper also acknowledges that expert count K remains a tuned hyperparameter. A real robot task may not have a fixed number of latent regimes. Flat walking, jumping, grasping, pushing, pulling, and fall recovery do not necessarily share the same complexity.

Is a soft mixture enough for hard switching?

PRISM-WM still computes the residual as Σₖ wₖvₖ. This convex-like blend is friendly to stable training, while some hybrid-system transitions can be closer to hard boundaries. The paper leaves composition beyond weighted sum as future work. The real question is whether a soft mixture can express sharp enough contact discontinuities, or whether planning will need something closer to discrete switching.

Does the orthogonal basis correspond to physical structure?

The paper does not claim that each expert corresponds to a specific physical event. The orthogonal basis lives in latent residual space, with representation learning between it and real contact labels. It may help the gate learn quasi-discrete switching, but it should not be read as "expert 1 is the left foot, expert 2 is friction."

Does the claim survive real robots and partial observability?

The paper includes zero-shot sim-to-sim transfer, but not real-robot deployment. Real systems include sensor noise, occlusion, delay, soft contact, actuation error, and hidden variables. Whether an orthogonal basis can still isolate useful uncertainty under those conditions is a real open question.

Implementation and reproduction caveat

The public code does contain the MoE dynamics and reward path: use_moe=true switches into MoEBlock, and use_orthogonal=true enters the orthogonalization path. Small real-environment ablations can run.

Those checks are still not a paper-level benchmark reproduction. In a one-seed, 100k-step cheetah-run-backwards sanity check I ran, the final rewards were:

This does not reproduce the direction prism_orth > baseline_mlp. It is better read as a diagnostic signal: the result may need more seeds, longer training, a closer DMC-30 setup, or a deeper implementation audit. One paper-code alignment issue worth checking is whether the MoE auxiliary loss in the current release participates in the gate gradients as intended. That does not refute the paper, but it is a reminder that reading a paper and trusting a release artifact are different acts.

What Structure Should A World Model Keep?

TD-MPC says a world model does not need to reconstruct the whole world. PRISM-WM adds the next constraint: it cannot erase the physical structure that changes the value of actions.

These two claims are compatible. A task-oriented world model can ignore background texture, shadows, and irrelevant pixels. If it serves a locomotion planner, it must preserve contact, impact, friction, and support, because those structures change which actions are valuable.

the small interface that matters

\[ \hat z_{t+1}=d_\theta(z_t,a_t) \]

The planner calls it repeatedly. The value function depends on it. Reward prediction follows it. If this function learns averaged physics, the planner may look sophisticated while optimizing inside the wrong future.

That is the most useful part of the paper. It pulls world model back from a large phrase into inspectable mechanisms: whether the transition function expresses hybrid dynamics, whether experts are non-redundant, whether rollout drift is reduced as horizon grows, and whether the gate switches meaningfully under perturbation.

For embodied AI, this may matter more than making the model larger. Robots do not move on a smooth mathematical plane. Every step touches the world. If a world model is meant to serve action, it should at least not average contact away.

PRISM-WM：世界模型不能把接触平均掉

June 2026

PRISM-WM 把问题压到 planner 反复调用的 transition function 上：这个接口需要适合 hybrid dynamics；接触、滑动、落地这些切换不能被一个单体 MLP 平均成同一条光滑曲线。

TD-MPC 已经把 world model 从一个很大的愿望，压成了一个更具体的控制接口。

它不要求模型还原整个世界。它只要求模型在行动前提供有用的未来：当前 observation 被编码成 latent state，planner 在这个 latent space 里测试候选动作序列，reward model 和 value model 给这些 imagined trajectories 打分。

这条链里最脆弱的是被 planner 反复调用的预测接口。

transition function

\[ \hat z_{t+1}=d_\theta(z_t,a_t) \]

这个函数回答的问题很直接：如果模型现在处在 latent state zₜ，并且尝试动作 aₜ，下一步 latent state 应该变成什么？

rollout 不是只预测一步。planner 会从当前 zₜ 开始，拿一串候选动作反复调用 dynamics model。

latent rollout

\[ \begin{aligned} (z_t,a_t) &\xrightarrow{d_\theta} \hat z_{t+1} \\ (\hat z_{t+1},a_{t+1}) &\xrightarrow{d_\theta} \hat z_{t+2} \\ (\hat z_{t+2},a_{t+2}) &\xrightarrow{d_\theta} \hat z_{t+3} \\ &\cdots \end{aligned} \]

每条候选 trajectory 都会被 reward model 和 terminal value 评分。planner 选分数最高的一条，只执行第一步，然后下个时刻重新规划。

问题就落在这里：如果 dθ 本身把物理世界里最关键的模式切换抹平了，planner 反复调用它时，到底在相信什么？

接触不是一条光滑曲线

机器人走路、跳跃、避障、抓取时，物理不是单一的平滑函数。

脚还没碰地是一种动力学；脚刚踩到地面又是另一种动力学。物体还没被抓住是一种状态；抓住之后，接触力、摩擦、约束都会改变。论文把这类系统称为 hybrid systems：连续运动中夹着离散的 regime switch。

术语注

这里的 regime 可以理解成“动力学模式”。脚在空中、脚踩到地面、物体被抓住，分别遵循不同的局部动力学；regime switch 就是系统在这些模式之间切换。

PRISM-WM 对比的 TD-MPC / TD-MPC2 这类 latent world model，通常用一个 monolithic MLP 来学 transition。

monolithic transition baseline

\[ (z_t,a_t)\rightarrow \mathrm{MLP}\rightarrow \hat z_{t+1} \]

monolithic MLP

monolithic 指“单体式”：所有状态和动作都交给同一个 MLP 处理；MLP 是多层感知机，也就是常见的全连接神经网络。这里对应 PRISM-WM 论文里的 monolithic TD-MPC2 / MLP baseline，不是一篇单独叫“普通 latent world model”的论文。

MLP 可以先理解成“固定长度向量到固定长度向量的函数拟合器”。在这里，它输入 (zₜ, aₜ)，输出下一步 latent state。LLM 里也有 MLP：Transformer block 通常是 attention + MLP / FFN。

这个 MLP 理论上可以拟合复杂函数，但实践里容易学成一个平均态。它会把 stance 和 flight、sticking 和 sliding、support force 和 friction residual 混在同一个连续函数里。对一步预测来说，这个错误可能还不明显；对 planner 来说，问题会被放大。planner 每多往前想一步，就多信一次这个被平滑过的 dynamics。

stance 支撑相。脚接触地面并承重，身体可以从地面获得支撑力。
flight 腾空相。脚离开地面，没有来自地面的支撑力。
sticking 粘着接触。接触点基本不发生相对滑动，近似静摩擦状态。
sliding 滑动接触。接触点沿表面发生相对运动，摩擦进入滑动状态。
support force 支撑力。地面对脚或身体的反作用力，决定能不能站住、跳起、落地和恢复平衡。
friction residual 摩擦残差。主要运动之外仍需由摩擦/滑动解释的变化；在 PRISM-WM 语境里，对应 latent residual dynamics 里和水平摩擦相关的成分。

TD-MPC 保留什么，PRISM-WM 改什么

这就是 PRISM-WM 的切入点。TD-MPC 已经解决了第一层压缩：不要重建所有 observation，只学习对控制有用的 task-oriented latent state。PRISM-WM 追问第二层：如果 planner 反复调用的 dθ 仍然是一个单体连续函数，它会不会把 hybrid dynamics 的边界平均掉？

到这里，需要把 TD-MPC 和 PRISM-WM 的边界确定好。TD-MPC 里的这套模型叫 TOLD，Task-Oriented Latent Dynamics。它至少包含几组接口。

接口 作用
zₜ = hθ(oₜ) 把当前 observation 编成 task-oriented latent state
ẑₜ₊₁ = dθ(zₜ, aₜ) 根据当前 latent state 和动作预测下一步 latent state
r̂ₜ = Rθ(zₜ, aₜ) 预测这一步的 reward
terminal value Vθ 在 H-step rollout 末端，用预测 latent state 估计剩余 return

这里的 θ 是神经网络参数的常用记号。hθ 是 encoder / representation network；zₜ 是 t 时刻的 latent state；aₜ 是 t 时刻的动作。planner 不是 world model 本身，它是使用 world model 搜索动作序列的算法。严格说，world model 也不等于 transition function；transition function 是其中最像“预测未来”的部分。

所以 PRISM-WM 没有否定 TD-MPC；它对 TD-MPC 提出一个更具体的判断：TD-MPC 的接口可以保留，问题不在于回到原始 observation reconstruction，也不在于推翻 MPC + value bootstrapping。PRISM-WM 保留 encoder 产生 zₜ、planner 做 latent rollout、reward/value 给 trajectory 打分这套框架；它改的是 dθ 的参数化方式，把单个 monolithic MLP 换成 gated、orthogonalized 的 expert residual dynamics。

PRISM-WM 改了哪个接口

PRISM-WM 的核心公式很短。

gated residual update

\[ \hat z_{t+1}=z_t+\sum_{k=1}^{K}w_{t,k}v_k(x_t) \]

逐个读：

  • zₜ当前 latent state。
  • aₜ候选动作。
  • xₜ通常由 zₜ 和 aₜ 拼起来。
  • wₜ,ₖ第 k 个 expert 在当前这一步被采用多少。
  • vₖ(xₜ)第 k 个 expert 对当前 context 输出的 residual direction。

路由权重

gating network 可以先理解成一个小的路由网络。它读取当前 context，也就是这一步的 latent state 和动作组合，先给每个 expert 打一个原始分数 sₜ,ₖ。

\[ w_{t,k}=\frac{\exp(s_{t,k})}{\sum_{j=1}^{K}\exp(s_{t,j})}, \qquad \sum_{k=1}^{K}w_{t,k}=1 \]

softmax 的作用是把这些原始分数变成一组非负权重，并且让它们加起来等于 1。于是 wₜ,ₖ 就有了很直观的含义：当前这一步，模型应该多相信第 k 个 expert。

注意，wₜ,ₖ 本身不是预测结果。真正提出变化方向的是 vₖ(xₜ)；wₜ,ₖ 只是乘在这个方向前面的系数。某个权重大，它对应的 expert 就对下一步 latent state 影响更大。

所以 PRISM-WM 把 dynamics function 从一个单独的 MLP，改成一组 local dynamics primitives 的组合。

gate + experts

\[ \begin{aligned} (z_t,a_t)&\xrightarrow{\mathrm{gate}}\{w_{t,k}\}_{k=1}^{K} \\ &\xrightarrow{\mathrm{experts}}\sum_{k=1}^{K}w_{t,k}v_k(x_t)\rightarrow \hat z_{t+1} \end{aligned} \]

gate 的工作不是显式识别“左脚支撑”或“右脚腾空”。论文也提醒过，经过 Gram-Schmidt 后的 expert 不应该被强行解释成一一对应的物理事件。它更像是在 latent residual space 里提供一组不重复的方向。真正的物理模式由 gate 在这些方向上的组合来表达。

换句话说，PRISM-WM 没有给每种接触状态手写一个专家。它让模型自己学一组可组合的 residual basis，然后让当前 (zₜ, aₜ) 决定怎么混合。

为什么只加 MoE 还不够

直接把一个 MLP 换成多个 expert，并不自动解决问题。

如果几个 expert 学到的是同一种函数，MoE 只是更大的 MLP。参数变多了，但 regime 没有真正分开。PRISM-WM 加的关键约束是 latent orthogonalization。

论文里做法是：每个 expert 先输出一个向量 uₖ，然后用稳定版 Gram-Schmidt 把它变成 vₖ。

orthogonalized residual basis

\[ \begin{aligned} \tilde v_k &= u_k - \sum_{i=1}^{k-1}\langle v_i,u_k\rangle v_i \\ v_k &= \frac{\tilde v_k}{\lVert \tilde v_k\rVert_2+\epsilon} \end{aligned} \]

这一步的作用很具体：让后来的 expert 输出减掉已经被前面 basis 解释过的部分。最后得到的 vₖ 更不容易挤到同一个方向上。

这个设计的品味在于，它没有把“物理模式”写死成标签。它只是给 dynamics residual 加了一个结构偏置：请尽量用不重复的方向解释未来变化。接触、滑动、落地、恢复平衡这些模式，理论上可以通过 gate 的权重变化在这些 basis 上组合出来。

这个区别也解释了论文为什么强调 orthogonalized MoE。vanilla MoE 能增加 capacity；orthogonalization 试图减少 expert redundancy。前者让模型更大，后者让模型更像在分解问题。

证据：它到底有没有减少 rollout drift

这篇论文最值得看的指标是 long-horizon fidelity。单点 reward 只能说明某个训练时刻的控制表现；horizon 拉长后的 fidelity，才直接对应这篇论文对 world model 的判断。

如果 PRISM-WM 的故事成立，模型在短 horizon 上未必显得惊艳，但随着 rollout horizon 变长，monolithic MLP 应该更快漂掉；orthogonalized MoE 应该更能保持 latent trajectory 的方向一致性。

在 Fig. 8 里，monolithic MLP 的 latent cosine similarity 随着 horizon 增长下降更明显；MoE 和 orthogonalized MoE 保持得更稳。右边的 reward fidelity 也在提醒一个细节：更大的 vanilla MoE 不一定更好，因为 over-parameterized experts 可能学到 redundant representations。

这些结果共同支撑一个判断：PRISM-WM 的收益应看 long-horizon rollout 里的 latent trajectory drift 下降；单纯容量增加解释不了全部现象。对 model-based RL 来说，这比单点 reward 更贴近 world model 的用途。

这篇论文真正改变了什么

PRISM-WM 把改动集中在 TD-MPC 的 transition function 上。

这个函数会被 planner 在 rollout 里反复调用；一旦它把接触模式平均掉，后面的 reward prediction、value estimate 和 action selection 都会沿着错误的未来走。

所以这篇论文提出了一个很具体的世界模型判断标准：world model 要服务 planner，transition function 就不能把接触、滑动、落地这些动力学切换平均成同一个连续函数。只保留 task-relevant information 不够；dynamics 的结构也要对。

TD-MPC 的问题意识是：别把 capacity 浪费在重建无关细节上。PRISM-WM 接着往下问：如果已经只学 latent dynamics，但这个 latent dynamics 把物理模式平均掉了，planner 仍然会被误导。

  • 被反复调用的对象planner 在每次 rollout 中都依赖 dθ。
  • 核心 failure modedθ 把 contact boundary 平滑掉。
  • 应看的证据long-horizon latent fidelity；单点 reward 不够。

仍然没解决的问题

regime 数量能否自动发现

论文主实验用 K=4，Fig. 10 也说明不同 K 的表现有差异。原文 limitations 也承认，expert count K 仍然是手调超参。更深的问题不是“K 怎么调”，而是一个真实机器人任务到底有多少 latent regimes，模型能不能自己发现。平地走、跳跃、抓取、推拉、摔倒恢复，接触结构不会固定在一个常数上。

soft mixture 是否足够表达硬切换

PRISM-WM 最后仍然用 Σₖ wₖvₖ 得到 residual。这个 convex-like blend 对稳定训练很友好，但 hybrid systems 的某些切换可能更接近硬边界。原文也把 beyond weighted sum 写进 future work。真正的问题是：soft mixture 能不能表达足够尖锐的 contact discontinuity，还是需要更接近 discrete switching 的 composition function？

orthogonal basis 是否真的对应物理结构

论文没有把每个 expert 宣称为某个具体物理事件，甚至明确说 orthogonal experts 不会一一对应真实物理事件。orthogonal basis 是 latent residual space 的结构约束，和真实接触标签之间还隔着一层表示学习。它可以帮助 gate 学出 quasi-discrete switching，但不能直接读成“专家 1 是左脚，专家 2 是摩擦”。这里最值得继续追问的是：模型学到的是物理分解，还是一个在 DMC / MuJoCo 上好用的 latent geometry？

真实机器人和 partial observability 下是否仍成立

论文做了 zero-shot sim-to-sim transfer，但这还不是 real robot。真实系统里有传感噪声、遮挡、延迟、软接触、执行误差，很多关键变量并不完全可观测。原文也把 real-world robotics 和 partial observability 写进 future work。PRISM-WM 的 orthogonal basis 能不能在这种更脏的观测条件下继续隔离 uncertainty，是它能否从 simulator result 走向 embodied world model 的关键。

实现和复现 caveat

公开代码里确实有 MoE dynamics / reward path，use_moe=true 会切到 MoEBlock，use_orthogonal=true 会进入 orthogonalization 路径，小规模真实环境 ablation 也能跑通。

但这些还不是 paper-level benchmark reproduction。我做过一个 cheetah-run-backwards 的 100k-step 单 seed sanity check，final reward 是：

baseline_mlp 388.82

这组结果没有复现 prism_orth > baseline_mlp 的方向。它更像一个诊断信号：也许需要更多 seed、更长训练、更贴近论文的 DMC-30 setting，或者更细的 implementation audit。尤其值得继续检查的是 paper-code alignment：当前 release 里 MoE auxiliary loss 看起来可能没有按预期参与 gate 的梯度更新。这不推翻论文，但它提醒我们，读 paper 和信 release artifact 是两件不同的事。

世界模型要保留什么结构

TD-MPC 给出的判断是：world model 不必还原整个世界。PRISM-WM 接着补上另一句：world model 不能把行动相关的物理结构抹掉。

这两个判断并不冲突。一个 task-oriented world model 可以不关心背景纹理、阴影和无关像素；但如果它要服务 locomotion planner，它就必须关心接触、冲击、摩擦和支撑这些会改变未来动作价值的结构。

the small interface that matters

\[ \hat z_{t+1}=d_\theta(z_t,a_t) \]

planner 反复调用它。value function 依赖它。reward prediction 也跟着它走。这个函数如果学成平均物理，后面的规划看起来再精致，也是在错误的未来里优化。

这就是这篇论文最有用的地方。它把 world model 从“理解世界”的大词拉回到可检查的机制：transition function 是否能表达 hybrid dynamics，expert 是否真的不重复，rollout drift 是否随 horizon 被压住，gate 是否在扰动时发生有意义的切换。

对 embodied AI 来说，这可能比一个更大的模型还重要。机器人不是在光滑的数学平面上移动。它每一步都在接触世界。世界模型如果想服务行动，至少不能把接触平均掉。
