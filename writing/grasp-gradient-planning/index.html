GRASP: gradient planning through a world model, made robust at long horizons

June 2026 · world models · planning · GRASP (arXiv:2602.00475)

A learned, differentiable world model should let you plan by gradient descent. But gradients through a high-dimensional visual world model are brittle: the optimizer exploits adversarial state directions, and a long rollout makes the gradient blow up like backprop-through-time. GRASP keeps gradient planning robust at long horizons with three changes to how the gradient is taken.

Why gradient planning through a world model is brittle

Planning here is fixed-goal: find an action sequence so that, under the learned dynamics \(F_\theta(s,a)\), an initial state \(s_0\) reaches a goal \(g\). Two things make it hard. A standard rollout applies \(F_\theta\) serially \(T\) times, so optimizing the action sequence is backprop-through-time — ill-conditioned, and worse as the horizon grows. And the loss landscape is jagged, so zero-order shooting methods (CEM, MPPI) degrade with horizon and action dimension.

The sharper problem is specific to taking gradients through a high-dimensional learned model. The state-input Jacobian \(\nabla_s F_\theta\) has no clean low-dimensional structure, so the optimizer finds adversarial state directions: a tiny perturbation \(s+\delta\) with \(g \approx F_\theta(s+\delta,\,a)\) regardless of the true start state — the planning analogue of an adversarial example in an image classifier. The paper's Theorem 1 makes this formal: a loss cannot at the same time (a) have dynamically feasible minimizers and (b) be insensitive to the state gradient \(\nabla_s F_\theta\). You cannot simply ignore the state gradient for free.

GRASP: three changes to the gradient

GRASP (Gradient RelAxed Stochastic Planner) keeps the differentiability but removes the brittleness with three moves, plus a synchronization step.

1. Virtual states (parallel, lifted). Instead of a serial rollout, treat the intermediate states as independent optimization variables — "virtual states" — with a soft dynamics-consistency penalty

\[ \mathcal{L}_{\text{dyn}} = \sum_{t} \big\lVert F_\theta(s_t, a_t) - s_{t+1} \big\rVert^2, \qquad s_0 \text{ fixed},\ s_T = g. \]

Every world-model evaluation is now parallel and better-conditioned, and it shares global minimizers with the original problem. The paper proves the payoff: a shooting method's gradient smoothness grows like \(|\lambda|^{2(T-1)}\) — it blows up with the horizon \(T\) — while the lifted method's bound is horizon-independent.

2. Stochastic states (exploration). Inject Gaussian noise into the state iterates (a Langevin-style update) to escape bad local minima. Noising the states rather than the actions keeps trajectories more dynamically feasible while still exploring.

3. Action-only gradients (grad-cut). Stop-gradient on the state inputs, so gradients flow only through the actions \(a_t\) in \(F_\theta(\bar s_t, a_t)\), avoiding the adversarial state directions. On its own this makes plans cling to the current rollout, so a dense one-step goal loss \(\sum_t \lVert F_\theta(\bar s_t, a_t) - g\rVert^2\) gives every action a task-aligned signal. Every so often a full serial-rollout gradient step refines the actions and enforces strict descent.

Evidence

GRASP is built on a DINO-WM world model and tested on Push-T, PointMaze, and WallSingle against CEM, GD (vanilla gradient through the serial rollout), and LatCo, at 500 trials per setting. The advantage is specifically at long horizons.

Horizon (Push-T)CEMGDGRASP
H = 4061.4% / 35.3s51.0% / 18.0s59.0% / 8.5s
H = 5030.2% / 96.2s37.6% / 76.3s43.4% / 15.2s
H = 607.2% / 83.1s16.4% / 146.5s26.2% / 49.1s
H = 802.8% / 132.2s6.4% / 161.3s10.4% / 58.9s
Success rate / median time-to-converge on long-range Push-T, from Table 1 of the paper (arXiv:2602.00475). LatCo collapses to ≤15% here and is omitted for space.

By H = 60–80, GRASP has both the highest success rate and the fastest convergence; the headline is up to +10% success at less than half the compute time. At short horizons (H = 10–30) all methods do well, so the gain is long-horizon-specific. Ablations confirm each move carries weight: action-only gradients reach 59.0% versus 46.6% when state gradients are allowed to flow, state noise at \(\sigma=0.5\) beats 0 and 1.0, and the periodic full-rollout sync step is what lifts success from near-zero.

Limitations

All reported metrics measure task success under the learned world model; the paper does not quantify whether the plans transfer to the true environment dynamics, and every experiment is in simulation, with no real robot. GRASP is built on one specific world model (DINO-WM), and at short horizons it shows little advantage. As a planner it inherits whatever errors the world model has — it makes gradient planning usable through a model, not the model correct.

GRASP：让梯度规划稳稳穿过世界模型

2026 年 6 月 · 世界模型 · 规划 · GRASP (arXiv:2602.00475)

一个学出来的、可微的世界模型，本应让你用梯度下降来做规划。但梯度穿过高维视觉世界模型时很脆：优化器会钻"对抗状态方向"，而长 rollout 又让梯度像 backprop-through-time 一样爆掉。GRASP 用三处对梯度的改动，让梯度规划在长 horizon 上保持稳健。

梯度规划为什么穿不稳世界模型

这里的规划是定目标的：找一段动作序列，使得在学到的动力学 \(F_\theta(s,a)\) 下，初始状态 \(s_0\) 到达目标 \(g\)。两件事让它难。标准 rollout 要把 \(F_\theta\) 串行调用 \(T\) 次，于是优化动作序列就是 backprop-through-time——病态，且 horizon 越长越糟。而 loss landscape 锯齿状，所以 zero-order 的 shooting 方法（CEM、MPPI）随 horizon 和动作维度退化。

更尖锐的问题，专属于"对一个高维学到的模型求梯度"。状态输入的 Jacobian \(\nabla_s F_\theta\) 没有干净的低维结构，于是优化器会找到对抗状态方向：一个微小扰动 \(s+\delta\)，使得 \(g \approx F_\theta(s+\delta,\,a)\) 不管真实起点是什么——这正是图像分类器里"对抗样本"在规划里的对应物。论文的 Theorem 1 把它形式化：一个 loss 不能同时（a）最小值动力学可行，且（b）对状态梯度 \(\nabla_s F_\theta\) 不敏感。你没法白白忽略状态梯度。

GRASP：对梯度的三处改动

GRASP（Gradient RelAxed Stochastic Planner）保留可微性，但用三招（外加一个同步步骤）去掉脆性。

1. Virtual states（并行、lifted）。不再串行 rollout——把中间状态当成独立的优化变量，称作"virtual states"——配一个 soft 的动力学一致性惩罚

\[ \mathcal{L}_{\text{dyn}} = \sum_{t} \big\lVert F_\theta(s_t, a_t) - s_{t+1} \big\rVert^2, \qquad s_0 \text{ 固定},\ s_T = g. \]

这样每次世界模型的评估都并行、条件更好，且与原问题共享全局最优。论文证明了收益：shooting 方法的梯度光滑度随 \(|\lambda|^{2(T-1)}\) 增长——随 horizon \(T\) 爆掉——而 lifted 方法的界与 horizon 无关。

2. Stochastic states（探索）。给状态迭代注入高斯噪声（Langevin 式更新）以逃离坏的局部最优。把噪声加在状态上（不加在动作上），能在探索的同时让轨迹更动力学可行。

3. Action-only gradients（grad-cut）。对状态输入做 stop-gradient，梯度只通过 \(F_\theta(\bar s_t, a_t)\) 里的动作 \(a_t\) 流动，避开对抗状态方向。单靠这个会让计划黏住当前 rollout，于是加一个 dense 的一步目标损失 \(\sum_t \lVert F_\theta(\bar s_t, a_t) - g\rVert^2\)，给每个动作一个任务对齐的信号。再每隔若干步，跑一次完整串行 rollout 的梯度步来精修动作、强制严格下降。

证据

GRASP 建在一个 DINO-WM 世界模型上，在 Push-T、PointMaze、WallSingle 上对比 CEM、GD（穿过串行 rollout 的普通梯度）、LatCo，每个设置 500 trials。它的优势专门体现在长 horizon。

Horizon（Push-T）CEMGDGRASP
H = 4061.4% / 35.3s51.0% / 18.0s59.0% / 8.5s
H = 5030.2% / 96.2s37.6% / 76.3s43.4% / 15.2s
H = 607.2% / 83.1s16.4% / 146.5s26.2% / 49.1s
H = 802.8% / 132.2s6.4% / 161.3s10.4% / 58.9s
长程 Push-T 的成功率 / 收敛中位时间，数据引自原文 Table 1（arXiv:2602.00475）。LatCo 在此 ≤15%，因篇幅略去。

到 H = 60–80，GRASP 同时拥有最高成功率和最快收敛；headline 是长 horizon 上至多 +10% 成功率、计算时间不到一半。短 horizon（H = 10–30）各方法都不错，所以它的收益是长 horizon 专属。消融证明三招都有分量：梯度只走动作时是 59.0%，让状态梯度也流则掉到 46.6%；状态噪声 \(\sigma=0.5\) 胜过 0 与 1.0；而那个周期性的完整 rollout 同步步骤，正是把成功率从接近零拉起来的关键。

局限

所有报告的指标，都是在学到的世界模型之下衡量任务成功；论文没有量化这些计划能否迁移到真实环境动力学，而且每个实验都在仿真里，没有真机。GRASP 建在一个特定世界模型（DINO-WM）上，且在短 horizon 上优势很小。作为一个规划器，它继承世界模型本身的全部误差——它让"穿过模型的梯度规划"变得可用，但并不让模型本身变正确。
